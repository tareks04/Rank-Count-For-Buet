# Changelog

## v1.0.0 — Initial Release

- Interactive PCM Nationwide Rank Estimator (`510–600` marks) modeled across all 10 Bangladesh education boards.
- Direct piecewise interpolation for Dhaka and Rajshahi boards, plus Dhaka-shape ("Likely") and linear ("Worst case") modeling for remaining boards.
- Live BUET top-10,000 shortlist verdict, cutoff bounds, and circular Top Pool gauge.
- HiDPI interactive Nationwide Rank Curve canvas with hover tooltip and click-to-set mark.
- Expandable Physics / Chemistry / Higher Math subject calculator and Light/Dark theme switcher.
- Automated GitHub Actions CI/CD workflow for GitHub Pages deployment and tagged GitHub Releases (`v*.*.*`).
